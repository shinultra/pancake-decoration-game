# 🥞 ホットケーキデコレーションゲーム

ふわっと焼けた1枚のホットケーキを、お皿のトッピングで自由にデコレーション。盛りつけのバランスからリアルタイムに **グレード** が算出され、**100 を超えると豪華なプレミアムトッピングが解放** される本格デコレーション・ブラウザゲームです。

## ▶ 今すぐプレイ

**👉 <https://shinultra.github.io/pancake-decoration-game/>**

PC・スマホ・タブレットどのブラウザでもそのまま遊べます。インストール不要。

## 遊び方

1. 中央のホットケーキの周りに、トッピングが乗った小皿が円状に並んでいます。
2. **小皿のトッピングをドラッグ** してホットケーキ上に運びます。
3. ホットケーキ上で離すと **配置確定**、外に離すと配置キャンセル（縁ぎりぎりは「はみ出し」減点）。
4. すでに置いたトッピングも **掴んで移動** 可能。ホットケーキから完全に離して離すと **削除**。
5. グレードが **100 を超えると ✨ プレミアム解放 ✨**。金箔・エディブルフラワー・マカロン・アイス・チョコ細工・スターアラザンの6種が使えるようになります。
6. 納得の盛りつけになったら **「完 成」** で結果発表！

## 操作

| 操作 | アクション |
| --- | --- |
| 配置 | 小皿のトッピングをドラッグ → ホットケーキ上で離す |
| 移動 | 置いたトッピングをドラッグ → 新しい場所で離す |
| 削除 | 置いたトッピングをドラッグ → ホットケーキの外で離す |
| 🔊 | サウンドのON/OFF（設定は端末に保存） |
| ? | このREADMEをGitHubで開く |
| 完成 | 結果発表へ |
| やり直し | 初期状態へリセット |

> 📱 **iPhone / iPadで音が出ないとき**: 本体側面のサイレント（消音）スイッチをOFFにしてください。Safari は OS のサイレントモードに従う仕様のため、コントロールセンターの音量だけでは鳴りません。

## 採点

合計140点満点。観点は4つ + ボーナス。

| 項目 | 点数 | 内容 |
| --- | --- | --- |
| 盛り | 0〜40 | ホットケーキ面積に対する適度なカバー率。スカスカも盛り過ぎも減点 |
| 均衡 | 0〜30 | トッピング群の重心がホットケーキ中心に近いか |
| 散らばり | 0〜30 | 等間隔に散らばっているほど高得点 |
| はみ出し | 0〜-30 | ホットケーキ外周に出た量だけ減点 |
| 彩りボーナス | +α | 種類数 / 隣接同色を避ける / プレミアム活用で加点 |

## 技術

- **Vanilla JavaScript + HTML5 Canvas + Web Audio API**
- 依存ライブラリゼロ・ビルド不要
- 画像アセットなしの **フルプロシージャル描画**
- 効果音とBGMも **シンセサイズドサウンド**（外部音源ファイル不要）
- マウス・タッチ統一の Pointer Events 対応
