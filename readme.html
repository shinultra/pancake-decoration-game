ホットケーキデコレーションゲーム

PANCAKE DECORATION GAME

ふわっと焼けた1枚のホットケーキを、周りに並んだお皿のトッピングで自由にデコレーション。 盛りつけのバランス・分布・はみ出し具合からリアルタイムに グレード が算出されます。 グレードが100を超えると、金箔・エディブルフラワー・マカロンなどのプレミアムトッピングが解放され、 ホットケーキ自体にも金色のオーラが灯ります。

遊び方

  1. 中央の ホットケーキ の周りに、トッピングが盛られた小皿が円状に並んでいます。
  2. 気になる小皿の トッピングをマウスでドラッグ（スマホは指でドラッグ）して、ホットケーキ上に運びます。
  3. ホットケーキの上で離すと 配置確定。ホットケーキの外で離すと配置キャンセル（縁ぎりぎりに置くと「はみ出し」減点になります）。
  4. すでに置いたトッピングも もう一度ドラッグして再配置 可能。ホットケーキから完全に離して離すと取り除けます。
  5. 画面上部の グレード が配置のたびに更新。100超えで ✨ PREMIUM UNLOCKED ✨ が発動し、外周のロック皿が解放されます。
  6. 納得の盛りつけになったら 完 成 を押して結果発表！ やり直しは やり直し から。

採点のしくみ

盛り (0〜40)
ホットケーキ面積に対する適度なカバー率を高評価。スカスカでも盛り過ぎでも減点。
均衡 (0〜30)
トッピング群の重心がホットケーキ中心からどれだけズレていないか。
散らばり (0〜30)
満遍なく等間隔に配置されているほど高得点。固まり過ぎは減点。
はみ出し (0 ~ -30)
ホットケーキ外周に出てしまった量だけ減点。
彩り ボーナス (+α)
種類数 / 隣接同色を避けた構成 / プレミアムの活用で加点。
合計140点まで狙えます。グレード 100 を超えるとプレミアムトッピング（金箔・エディブルフラワー・マカロン・アイス・チョコ細工・スターアラザン）が解放されるので、まずは通常トッピングだけで 100 を目指しましょう。

起動方法

方法A：ローカルサーバを立てる（推奨）

このゲームはES Modulesを使うため、file:// 直開きはブラウザによって動きません。ターミナルでプロジェクトのフォルダに入り、簡易サーバを起動してください。

# プロジェクトフォルダへ移動
cd "そまそま"

# Python 3 が入っていれば 1 コマンドでOK
python3 -m http.server 8765

ブラウザで http://localhost:8765/ を開けばプレイ開始です。

Node.jsが入っているなら npx serve でもOK。VS Codeの「Live Server」拡張も使えます。

方法B：Chrome を一時的に file:// で許可して直開き

サーバを立てたくない場合、Chrome を以下のフラグ付きで起動すれば index.html を直接ダブルクリックでも動きます（推奨はしません）。

open -na "Google Chrome" --args --allow-file-access-from-files
普段使いのChromeをこのフラグで起動するのはセキュリティ的にお勧めできません。プレイ後は通常のChromeに戻してください。

動かす
置いたトッピングをドラッグ → 新しい場所で離す
取り除く
置いたトッピングをドラッグ → ホットケーキの外で離す
完成
画面右上の「完 成」ボタンで結果発表
やり直し
「やり直し」ボタンで初期状態へ（プレミアム解放もリセット）
スマホ
指でそのままドラッグ＆ドロップ可能
